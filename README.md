# Sort Array of Strings in C

**Author:** M.Likitha

## Description

This program stores five strings in a character array and sorts them
in alphabetical order using `strcmp()` and `strcpy()`.

## File

sort_strings.c

## Concepts Used

- Array of strings
- `strcmp()`
- `strcpy()`
- Nested loops
- String sorting
- Character arrays

## How to Run

gcc sort_strings.c -o sort_strings
./sort_strings

## Sample Output

Enter 5 words:
Word 1: Mango
Word 2: Apple
Word 3: Orange
Word 4: Banana
Word 5: Grapes

Strings in alphabetical order:
Apple
Banana
Grapes
Mango
Orange
